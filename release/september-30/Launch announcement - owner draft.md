# The Travel Update
This week, getting from point A to point B is getting quicker.

**TRAVEL**
- Mounts such as horses, camels, donkeys, and mules, will all receive a 3x movement-speed boost when on supported surfaces in the overworld. base speeds still affect mounts, so a horse with higher base speed will still be faster.
- Player-occupied minecarts can reach up to 32 bps (block per second) when on powered rails and with boosted stopping for unpowered rails.
- Elytra and rocket behaviour have had some tweaks too, you'll hear more about that when the end is opening.

**A LITTLE HOUSEKEEPING**
- TAB no longer displays player pings, it now displays Nooks balances, sorts players by richest first, and shows the server TPS.
- Some quality of life tweaks to the way quests handle notifications

Weekly quests refresh wednesdays at 02:00 UK time, this is the same time any future content drops will happen.

The update is now live, so are this weeks new quests! Build a road, lay down some tracks, and get travelling!
