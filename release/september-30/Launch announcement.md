# The Travel Update
This week, getting from point A to point B is getting quicker.

**TRAVEL**
- Mounts such as horses, camels, donkeys and mules receive a 3x movement-speed boost on supported surfaces in the Overworld. Base speeds still matter, so a faster horse keeps its advantage.
- Player-occupied minecarts can reach up to 32 blocks per second on suitable powered routes, with stronger braking for unpowered powered rails.
- We'll revisit elytra and rocket changes when planning the End opening. Their behaviour is unchanged tonight.

**A LITTLE HOUSEKEEPING**
- TAB replaces numeric ping with Nooks balances, sorts players richest first and shows server TPS.
- Quest progress notifications are less frequent; progress still counts between messages, and completion appears immediately.

Weekly quests refresh Wednesdays at 02:00 UK time, alongside future content drops.

The update is now live, and so are this week's new quests! Build a road, lay down some tracks, and get travelling!
